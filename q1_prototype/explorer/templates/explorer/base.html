How it works

Data. WBG Corporate Scorecard API (results, client context, metadata, projects), World Bank Data360 and the Projects API, loaded by a pipeline into a local read-only database (snapshot FY{{ latest_fy }}).

Questions. A fast model classifies each message (filter, analyze, explain, research, create artifact, clarify, out of scope). Analysis runs typed, read-only queries; answers and artifacts are written only from their results.

Verified numbers. Every figure taken from data links to its source row: 12.1M✓. Numbers that can't be traced are marked 12M⚠.

Achieved vs expected. “Expected” is what the active portfolio is expected to deliver, not a corporate target.
