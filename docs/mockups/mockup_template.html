How it works

Data. WBG Corporate Scorecard API (results, client context, metadata, stories), loaded by a pipeline into a local database.

Questions. A fast model classifies each message (set filters, analyze, explain, create artifact, clarify, out of scope). Analysis runs typed, read-only queries; answers and artifacts are built only from their results.

Artifacts. Figures, video explainers and briefing decks are generated from verified data. Each one can be exported as a Jupyter notebook that re-downloads the same data from the Scorecard API and reproduces it.

Verified numbers. Every figure links to its source row: 12.1M✓. Untraceable numbers are marked 12M⚠.
